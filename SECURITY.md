# Security Policy

## Scope

scam-with-friends-trainer is a local desktop trainer. It does not phone home, does not run remote code, and does not touch anything outside the game process it attaches to.

## Reporting

If you find a vulnerability — e.g. a path traversal in the config loader, or an unsafe eval in a processor — please email the maintainer listed in `pyproject.toml` or open a private security advisory on GitHub. Do not open a public issue for security bugs.

## Out of scope

- Getting banned in-game. Use at your own risk.
- Anticheat evasion requests. Not what this project is for.
- "My friend got scammed" complaints. That's the game, not the trainer.
